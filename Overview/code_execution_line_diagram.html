Transcript Intake Agent - actual module call paths from current source (main.py, watcher, ADO client, demo scripts).

End-to-end execution map

[Manual or scheduler trigger]
    |
    +--> python src/main.py --mode <mode> [--input ...] [flags]
    |       |
    |       +--> mode=dry-run
    |       |      read_transcript()                  src/transcript_reader.py
    |       |      -> clean_paragraphs()              src/transcript_cleaner.py
    |       |      -> chunk_transcript()              src/transcript_chunker.py
    |       |      -> writes output/transcript_chunks.json
    |       |
    |       +--> mode=extract
    |       |      run_dry_run()
    |       |      -> detect_candidates()             src/candidate_detector.py
    |       |            -> call_llm()                src/llm_client.py
    |       |      -> deduplicate_candidates()        src/candidate_deduplicator.py
    |       |      -> writes output/candidates.json
    |       |
    |       +--> mode=classify
    |       |      (uses output/candidates.json if present, else run_extract)
    |       |      -> classify_candidates()           src/classifier.py
    |       |            -> call_llm() per candidate  src/llm_client.py
    |       |      -> validate_all_rows()             src/validators.py
    |       |      -> writes output/classified_rows.json
    |       |
    |       +--> mode=payload
    |       |      (uses output/classified_rows.json if present, else run_classify)
    |       |      -> confidence split                main._split_rows()
    |       |      -> export_review_workbook()        src/review_exporter.py
    |       |      -> build_sharepoint_payload()      src/power_automate_client.py
    |       |      -> generate_report()               src/report_generator.py
    |       |      -> writes review_rows.xlsx / sharepoint_payload.json / ai_opportunity_report.html
    |       |
    |       +--> mode=push
    |       |      run_payload()
    |       |      -> push_to_power_automate()        src/power_automate_client.py
    |       |
    |       +--> mode=weekly   (full pipeline)
    |       |      Step 0: ado_client.sync_all_weeks()               src/ado_client.py
    |       |      clear stale output/{transcript_chunks,candidates,classified_rows}.json
    |       |      run_payload()
    |       |      resolve meeting date/week/month                    src/period_utils.py
    |       |      build_queue_from_rows()                            src/review_queue.py
    |       |      archive week artifacts -> output/weeks/YYYY-MM-DD/
    |       |      update_master(primary_rows, date)                  src/master_exporter.py
    |       |      if --push-ado:
    |       |          review gate (approved unless --skip-review-gate)
    |       |          get_or_create_epic()                           src/ado_client.py
    |       |          push_work_item(row, epic_id) per row           src/ado_client.py
    |       |          write ADOWorkItemId/Url/Status/PushedAt back to archived classified_rows.json
    |       |      ingest_week(primary_rows, meeting_date)            src/history_store.py
    |       |      if backdated:
    |       |          rebuild_all_reports(history)
    |       |              -> generate_weekly_report()                src/trend_reporter.py
    |       |              -> generate_monthly_report()               src/trend_reporter.py
    |       |              -> update_master() for each week           src/master_exporter.py
    |       |              -> build_meeting_presentation()            src/presentation_builder.py
    |       |      else:
    |       |          generate_weekly_report(history, date, ..., week_rows, triage_rows)
    |       |              -> weekly_analysis()                       src/trend_analyzer.py
    |       |              -> build_report_html() + progress tab      src/report_generator.py
    |       |          generate_monthly_report(history, month)
    |       |              -> monthly_analysis()                      src/trend_analyzer.py
    |       |      build_meeting_presentation(history, date, rows)    src/presentation_builder.py
    |       |
    |       +--> mode=monthly
    |       |      load_history()                                     src/history_store.py
    |       |      -> generate_monthly_report()                       src/trend_reporter.py
    |       |
    |       +--> mode=rebuild
    |       |      load_history()
    |       |      -> rebuild_all_reports() (all weeks, all months, master, presentation)
    |       |
    |       +--> mode=review
    |       |      load output/weeks/<date>/classified_rows.json
    |       |      migrate_list()                                     src/schema_migrations.py
    |       |      build/load queue                                   src/review_queue.py
    |       |      interactive A/R/E/K/Q loop
    |       |      -> review_queue action_*() -> feedback_store       src/feedback_store.py
    |       |      -> apply_queue_to_rows()
    |       |      -> writes queue.json + updated archived classified_rows.json
    |       |
    |       +--> mode=apply-feedback
    |       |      feedback_store.load_all()
    |       |      -> feedback_applier.build_staged_version()         src/feedback_applier.py
    |       |      -> writes config/feedback_staging/<version>/*
    |       |
    |       +--> mode=eval
    |       |      evaluator.load_examples()                          src/evaluator.py
    |       |      -> evaluator.run_eval() -> write_eval_report()
    |       |
    |       +--> mode=promote-feedback
    |              feedback_applier.promote_version(version)
    |              -> eval gate
    |              -> append examples + append rules to classify skill
    |
    +--> python src/watch_transcripts.py
    |       polls input/transcripts/
    |       waits for stable signatures
    |       subprocess.run([python, src/main.py, --input <file>, --mode weekly])
    |       tracks processed file signatures in output/history/processed_files.json
    |
    +--> python src/ado_client.py --sync|--test|--push-all
    |       standalone ADO utility (same module used by weekly mode)
    |
    +--> python demo/build_demo_deck.py
    |       builds demo/AI_Transcript_Intake_Agent_Demo.pptx
    |
    +--> python demo/build_speaker_notes.py
            builds demo/AI_Transcript_Intake_Agent_Speaker_Notes.docx

AI boundary (where model calls actually happen)

src/candidate_detector.py -> detect_candidates() -> llm_client.call_llm() src/classifier.py -> classify_candidates() -> llm_client.call_llm() src/presentation_builder.py -> _llm_slide_content() (meeting deck text)

Everything else is deterministic Python, file I/O, spreadsheet generation, HTML rendering, and ADO/HTTP API calls.
