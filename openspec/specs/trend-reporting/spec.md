## MODIFIED Requirements

### Requirement: Opportunity cards display MaturitySignal badge
HTML opportunity cards generated by `src/report_generator.py` SHALL display `MaturitySignal`
as a colored badge in the card header alongside the existing AIUseCaseType and SignalStrength
badges.

Badge color mapping:
- `Aspirational` → amber / yellow (`#D97706`)
- `In Progress / Piloting` → blue (`#2563EB`)
- `Delivered / Active Today` → green (`#059669`)
- `Unknown` or blank → gray (`#6B7280`)

#### Scenario: Delivered opportunity renders green badge
- **WHEN** a card's `MaturitySignal` is `"Delivered / Active Today"`
- **THEN** the card header SHALL display a green badge labeled "Delivered"

#### Scenario: Aspirational opportunity renders amber badge
- **WHEN** a card's `MaturitySignal` is `"Aspirational"`
- **THEN** the card header SHALL display an amber badge labeled "Aspirational"

#### Scenario: Unknown MaturitySignal renders gray badge
- **WHEN** `MaturitySignal` is `"Unknown"` or absent
- **THEN** the card header SHALL display a gray badge labeled "Unknown"

### Requirement: MaturitySignal column in master and review XLSX
`src/master_exporter.py` and `src/review_exporter.py` SHALL include `MaturitySignal`
as a column immediately after `ConfidenceLevel` (column G) in the output workbooks.

#### Scenario: XLSX column order maintained
- **WHEN** the master or review workbook is generated
- **THEN** column F SHALL be `ConfidenceLevel` and column G SHALL be `MaturitySignal`

### Requirement: Triage section in weekly HTML report
The weekly HTML report SHALL include a collapsible "Triage / Low Confidence" section below the main opportunity cards. This section SHALL display the count of suppressed candidates and list their titles and evidence summaries in a simplified card layout (no full card styling). If no candidates were suppressed, this section SHALL be omitted entirely.

#### Scenario: Suppressed candidates present
- **WHEN** one or more candidates were routed to Triage during the weekly run
- **THEN** the weekly HTML report includes a collapsed "Triage (N candidates)" section listing their titles and evidence

#### Scenario: No suppressed candidates
- **WHEN** all candidates met the confidence threshold
- **THEN** the Triage section is omitted from the weekly HTML report

### Requirement: Suppressed candidate transparency counter
The weekly HTML report summary header SHALL display a "candidates suppressed" count alongside the existing opportunity count, so reviewers understand the full extraction picture.

#### Scenario: Summary with suppressed count
- **WHEN** the weekly report is generated and N candidates were suppressed
- **THEN** the summary header reads "X opportunities identified, N suppressed (low confidence)" or similar
- **THEN** when N = 0 the suppressed count is omitted from the header
