# Skill: Review Rules

Before SharePoint push, review:
- Is this a real AI opportunity?
- Is it duplicate?
- Is the title clear?
- Is the problem/pain point accurate?
- Is the AI Use Case Type correct?
- Is Human-In-The-Loop required?
- Are guardrails adequate?
- Is the suggested owner/SME reasonable?
- Is the evidence summary grounded in the transcript?
- Should this remain Needs Review?

The agent should never approve, publish, or scale an item automatically.
