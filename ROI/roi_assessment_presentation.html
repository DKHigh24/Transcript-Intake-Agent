Time Savings ROI Assessment

Program: Transcript Intake Agent (weekly + monthly reporting + Azure DevOps work item tracking)

Scenario: Pipeline now runs with GitHub Copilot SDK by default (no OpenAI key required).

Prepared: 2026-06-23

1) Executive Summary

Automating transcript intake, opportunity extraction/classification, report generation, and Azure DevOps work item lifecycle management reduces labor from an estimated 9.0 hours per weekly cycle to 1.5 hours (human review + ADO oversight), saving about 7.5 hours per week. The ADO integration alone accounts for approximately 1.7 hours of additional weekly savings by eliminating manual work item creation, status tracking, and opportunity-to-task traceability.

8) Assumptions and How to Recalibrate

  • Cadence assumed: 1 transcript per week.
  • Base-case runtime credits assumed: 30 per run.
  • Manual baseline assumed: 9.0 hours per run.
  • Automated baseline assumed: 1.5 hours per run (including review + ADO oversight).
  • ADO push cycle assumed: monthly (÷4.3 for weekly average); actual savings scale with push frequency.
  • ADO status tracking baseline: 1.0 hr/week manual; actual varies by team follow-up process.
